# Ciberseguridad

Repositorio destinado al desarrollo y experimentación de scripts y herramientas
relacionadas con ciberseguridad, utilizando Python y otras tecnologías.

## Propósito

Este repositorio será utilizado para desarrollar, probar y documentar
herramientas orientadas a actividades de ciberseguridad ofensiva y defensiva.

El proyecto `celsius.py` constituye el primer ejercicio utilizado para
establecer y validar el flujo de trabajo de desarrollo con:

- Google Colab
- Python
- GitHub
- ChatGPT
- Codex

## Proyecto inicial: celsius

`celsius.py` es un ejercicio de Machine Learning desarrollado inicialmente
en Google Colab.

El programa utiliza TensorFlow para entrenar una red neuronal sencilla que
aprende la relación entre grados Celsius y grados Fahrenheit.

Este proyecto se utiliza como ejemplo para aprender el ciclo de desarrollo,
gestión del código y colaboración con herramientas de Inteligencia Artificial.
